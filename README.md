## 🚀 Live-Projekte

### 🏀 [Bucket Data](https://bucket-data.lovable.app)
**NBA-Matchup-Analyse auf einen Blick.** Spiel auswählen und die Stats beider Teams im direkten Vergleich sehen: Form der letzten Spiele inklusive Gegnerstärke, Tabellenplatz, Verletzungen, vermutliche Starting Five. Dazu Liga-Tabellen, Spieler-Ranglisten und eine NBA-Cup-Ansicht.

- ✅ Live und aktiv genutzt, in deutschen Basketball-Foren vorgestellt
- 💸 Läuft komplett ohne kostenpflichtige APIs
- 🛠️ React · TypeScript · Lovable · Claude Code

[**→ App öffnen**](https://bucket-data.lovable.app)

### 🌤️ [Weather Destination Finder](https://weather-destination-finder.lovable.app)
**Wo ist in den nächsten Tagen das Wetter, das ich will?** Du stellst deine Wunschbedingungen ein (Temperatur, Bewölkung, Regen, Zeitfenster), und eine Heatmap zeigt dir, wohin sich ein spontaner Trip lohnt. Gedacht für die Flucht vor Hitze, vor Dauerregen oder für das perfekte Wetter zum Radfahren.

- 🗺️ Interaktive Heatmap mit eigener Bewertungslogik pro Ort und Tageszeit
- 🛠️ React · TypeScript · Leaflet · CARTO · Lovable · Claude Code

[**→ App öffnen**](https://weather-destination-finder.lovable.app)
